# Как начать в Claude Code

## Шаг 1. Собрать папку

Создай папку, например на рабочем столе, назови `advokat-crm`. Положи в неё:

- `advokat_crm.html` — приложение
- `TZ_CRM_advokat.md` — техническое задание
- `CLAUDE.md` — правила работы
- копию файла АдвокатДок

## Шаг 2. Открыть папку в Code

В десктопном приложении Claude открой вкладку Code и выбери **именно эту папку**, а не
рабочий стол и не домашнюю папку. Code видит только выбранный каталог.

## Шаг 3. Проверить, что он видит файлы

Первым сообщением напиши:

> Покажи список файлов в проекте.

В ответе должны быть все четыре файла. Если их нет — открыта не та папка, вернись к шагу 2.

## Шаг 4. Дать контекст

> Прочитай CLAUDE.md и TZ_CRM_advokat.md. Скажи одной фразой, что за проект и какой этап следующий.

Если ответ по делу — контекст загружен, можно работать.

---

## Если Code не видит файлы или отвечает невпопад

Вставь это сообщение целиком — оно самодостаточно и не требует файлов:

---

Меня зовут Адамов Тажиб Таривердиевич, я адвокат, реестровый номер 77/9954, практика в Москве,
уголовные и административные дела. Обращайся ко мне на «ты», отвечай по-русски. Называй себя
Лира, в женском роде.

Мы разрабатываем CRM для адвокатского кабинета. Это один самодостаточный HTML-файл без
сборщика: шифрование WebCrypto, хранение в IndexedDB, реестр уголовных дел, склонение ФИО
по падежам, парсер заявок Адвокатской палаты Москвы по ст. 51 УПК РФ.

Правила работы:
- не пиши код, пока я не подтвердил план;
- после каждой задачи давай блок: что стоит учесть, контраргументы, следующий шаг;
- при обсуждении работай как второй адвокат — показывай слабые места и риски;
- сроки и нормы УПК, УК, КоАП проверяй поиском по действующей редакции, не по памяти;
- после правки скрипта проверяй синтаксис через node --check.

В папке проекта лежат файлы: advokat_crm.html — приложение, TZ_CRM_advokat.md — техническое
задание, CLAUDE.md — эти же правила подробнее. Прочитай их и скажи, что дальше по плану.

## Что делать, если всё равно не выходит

Работа продолжается в обычном чате Claude — там всё это уже работает. Code нужен только когда
дойдём до публикации приложения на GitHub Pages, а это третий этап.
